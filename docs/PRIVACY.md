# Данные остаются локально

PhotoFlow не имеет собственного сервера и не загружает фотографии, каталог или USB-идентификаторы в облако. Для просмотра и импорта не нужен аккаунт PhotoFlow.

Каталог SQLite, звёзды, отбор и пути импортированных файлов хранятся в `%LOCALAPPDATA%/PhotoFlow`. Для изолированного тестирования можно задать `PHOTOFLOW_DATA_DIR`. Ошибки приложения записываются локально в `last-error.log`; журнал может содержать пути, поэтому его нельзя публиковать без проверки.

Сканирование получает метаданные. Видимые локальные превью создаются средствами Windows. USB-превью запрашивают только отдельный ресурс миниатюры; отсутствие миниатюры не запускает чтение оригинала. Явный импорт читает выбранный оригинал. Функций удаления и изменения исходных медиа в этой версии нет.

Тестовые USB-данные, реальные фотографии, базы, логи, полные пользовательские пути и идентификаторы устройств исключены из публикации. Для документации используются только процедурные демонстрационные изображения. Метаданные EXIF в этих JPEG отсутствуют.

Компоненты Windows/.NET/Windows App SDK имеют собственные лицензии и системную диагностику. Это не облачное хранилище PhotoFlow; системные правила диагностики определяются Windows и лицензиями соответствующих компонентов.

Перед отправкой issue заменяйте реальные пути, имена личных файлов и USB-ID на примеры. Для уязвимостей используйте [SECURITY.md](../SECURITY.md).
