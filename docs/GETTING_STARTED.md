# Начать работу

## Локальная папка

Откройте PhotoFlow.App.exe и нажмите **Открыть папку**. Индексирование не создаёт копии оригиналов. Система может читать содержимое видимых файлов для создания превью; это отдельная операция просмотра.

Галочка выбирает файл для импорта, звезда сохраняет избранное только в PhotoFlow. Двойной клик открывает просмотр. Поиск работает по имени; фильтры — по типу, сортировка — по дате, имени, размеру или формату.

**Выбрать все** и Ctrl+A охватывают все совпадения с фильтром, включая карточки, которые ещё не загружены на экран. Нижняя панель считает выбор во всём текущем источнике, включая скрытое фильтром. **Снять** очищает выбор источника.

## Телефон

1. Подключите кабель передачи данных и разблокируйте телефон.
2. Android: выберите режим передачи файлов. iPhone: подтвердите доверие; совместимость пока не проверена.
3. Откройте **USB-устройства**, выберите устройство и начните сканирование.
4. При отсутствии отдельной миниатюры будет заглушка. PhotoFlow не скачивает полный оригинал ради USB-превью.

USB показывает только объекты, предоставленные устройством Windows. Облачные оригиналы и системные альбомы могут быть недоступны. Дата WPD-created — предварительная дата, не подтверждённый EXIF.

## Импорт

Нажмите **Импортировать**, выберите папку и проверьте набор перед запуском. Существующие файлы не перезаписываются; новое имя получает числовой суффикс. Перенос идёт через отдельный `.part`, проверяется размер при его наличии и SHA-256 записанного файла.

**Остановить** отменяет операцию между вызовами устройства. Завершённые объекты отмечаются импортированными и снимаются с выбора; оставшиеся сохраняют отметки. Постоянной очереди заданий и автоматического восстановления после USB-обрыва пока нет. Для повторного подключения сначала обновите источник.

## Клавиши

| Клавиша | Действие |
|---|---|
| Ctrl+A | Все совпадения с фильтром |
| Ctrl+Shift+A | Снять выбор в источнике |
| Shift+клик | Диапазон загруженных карточек |
| F | Избранное последнего выбранного кадра |
| Двойной клик | Просмотр |

RAW-пары и Live Photos пока показаны отдельными объектами. Распознавание RAW по расширению не означает поддержку декодирования. HEIC/видео зависят от доступных кодеков Windows.

## Изменения 0.2.1

Миниатюры показываются целиком, с сохранением пропорций. По краям возможны свободные поля.

Сканирование пропускает скрытые и системные объекты, папки с точкой в начале имени, Android, cache/caches, thumbnails/thumbs, корзины и известные папки удалённых файлов. В Android исключается также Android/media; обычные альбомы DCIM, Pictures и выбранные пользовательские папки продолжают сканироваться. Это фильтр путей и признаков файлов, а не доступ к состоянию системной галереи Android: нестандартные папки приложений могут потребовать дополнительных исключений.

Записи из известных служебных папок убираются из старого каталога при запуске. Для удаления записей об исчезнувших с телефона или диска фотографиях выберите источник слева и нажмите обновление. После полного сканирования без предупреждений отсутствующие записи удаляются только из каталога PhotoFlow. При отмене, ошибке или неполном доступе они сохраняются. Оригиналы и импортированные копии не удаляются.
