Один Android прошёл базовую проверку списка, миниатюр и выборочного импорта. Остальная матрица открыта; подробности в STATUS.md.

## Процедура

1. Выполнить `devices`, записать модель, ОС, драйвер и тип USB-подключения. PnP ID может содержать серийный номер — хранить отчёты локально, не публиковать личные данные.
2. `scan --device-id ... --limit 100 --output ...`, затем 1000, 10000 и полный набор, если доступен. Записать время первого объекта, длительность, количество, предупреждения. При лимите скан явно помечается неполным. Список не запрашивает ресурсы оригиналов.
3. Для нескольких JPEG/HEIC/RAW/видео отдельно вызвать `thumbnail`, записать доступность и размер ресурса. `.bin` содержит исходные байты; формат не предполагается JPEG. Не выдавать отсутствие thumbnail за ошибку всего сценария и не включать скрытый fallback на оригинал.
4. Для одного согласованно выбранного объекта выполнить `copy` в новую пустую папку; проверить размер, SHA-256, открытие файла и неизменность оригинала. При неизвестном размере проверка SHA подтверждает сохранение полученных байтов, но не полноту исходного объекта.
5. Повторить с физическим отключением в процессе чтения. Убедиться, что конечный неполный файл не появляется. Повторное подключение требует нового скана и актуального object ID; постоянная очередь ещё не реализована.
6. Сопоставить даты с известной датой съёмки. Зафиксировать отсутствие EXIF/таймзоны; не считать WPD-created датой съёмки без отдельного доказательства.
7. Для iCloud «Оптимизация хранилища» отдельно отметить, какие оригиналы действительно доступны по USB.

## Контрольная точка

Если телефон не отдаёт миниатюры, P0 возвращает «недоступно». Решение о временной загрузке оригиналов в ограниченный кэш принимается отдельно, после измерений. Наличие адаптера WPD не означает прохождения P0, P1 или критериев приёмки из ТЗ.
