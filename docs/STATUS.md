# Проверено в 0.2

Версия: **0.2.0 early preview**. Проверка: 25 октября 2026 года.

## Реализованный срез

- WinUI 3: тёмная галерея, крупные превью, поиск, фильтры, сортировка, просмотр, избранное, подтверждение импорта и отмена.
- Виртуализация GridView/ItemsWrapGrid и SQL-страницы по 200 карточек. В памяти ограничено число удерживаемых превью: 64; невидимые запросы отменяются.
- SQLite/WAL: каталог, звёзды, отбор, история завершённых переносов. Массовое действие работает по всему совпадающему SQL-набору.
- WPD: read-only подключение, инкрементальные порции метаданных, отдельные thumbnail-ресурсы, поток выбранного оригинала, просмотр структуры папок. Запросы миниатюр могут выполняться между порциями сканирования.
- Перенос через собственный `.part`, проверка размера при его наличии, SHA-256 полученного потока и повторно прочитанного файла, конечное имя без перезаписи. Импорт проверяет свободное место и сохраняет завершение каждого объекта.

## Проверки

| Область | Фактический результат |
|---|---|
| .NET 10 / WinUI 3 | Release-сборка решения успешна |
| xUnit | 23 теста прошли, без ошибок и пропусков |
| Большой локальный каталог | Перечисление 10 000 искусственных файлов; SQL-выбор всех 5 000 RAW из 10 000 записей |
| Постоянные отметки | База переоткрыта, звёзды/выбор сохраняются; обновление object ID не теряет отметки при подтверждённом сопоставлении |
| Изменившийся локальный объект | Новый fingerprint по тому же пути не наследует избранное и отметку импорта |
| Поиск | Буквальные `%`/`_`, кириллица без различия регистра, SQL-подобная строка не меняет запрос |
| Локальный перенос | Выборочный перенос, SHA-256, отмена, искусственный обрыв, повтор целого файла, конфликты имён, неизменность исходников |
| UI | Открытие галереи, демонстрационные превью, выбор кадра, итоговый объём и экран избранного проверены визуально; полная UI-регрессия ещё не проведена |
| Android USB | Получены 100 медиа без предупреждений и 3 разные валидные JPEG-миниатюры без чтения оригиналов |
| Android: выбранный тестовый набор | Перенесены 28 JPEG, размеры и SHA-256 проверены; все копии читаются как изображения, все 28 оригиналов остаются доступны, `.part` не осталось |

USB-проверка относится к **одной конфигурации Android**, не ко всем телефонам. Имена, пути, модель, серийные номера, фотографии и сырые журналы теста не публикуются. Тестовые исходники не изменялись и не удалялись.

## Открытые ограничения

- iPhone и второй Android не проверены. Реальный обрыв кабеля и восстановление после переподключения ещё не испытаны.
- Нет LibRaw, камерной матрицы RAW, EXIF/QuickTime-уточнения дат, RAW+JPEG/Live Photos-групп и точного поиска дубликатов. Даты файлов/WPD явно предварительные.
- Видео/HEIC/RAW-превью зависят от возможностей Windows; наличие расширения в списке не доказывает декодирование.
- Нет постоянной очереди заданий и автоматической докачки. Завершённые переносы сохраняются; оставшиеся отметки можно обработать повторно.
- Shift-диапазон охватывает загруженные карточки; Ctrl+A охватывает весь SQL-фильтр.
- Удалённые объекты не очищаются автоматически из каталога; при недоступном оригинале превью может быть заглушкой. Переименование/замена/смена PnP ID требуют дополнительной проверки идентичности.
- Проверка 50 000 объектов, длительная прокрутка, строгий бюджет памяти в байтах и полный набор доступности/масштабирования ещё впереди. Ограничение 64 превью не является измерением общего потребления памяти.
- Дистрибутив — preview-архив, не установщик. Нужен .NET 10 Runtime x64; Windows App Runtime включён.

SHA-256 при неизвестном исходном размере подтверждает сохранность полученных байтов, но не доказывает полноту неизвестного оригинала. Метаданный fingerprint — кандидат сопоставления, не хеш содержимого.
