# Сообщить о проблеме

Если проблема раскрывает личные файлы, USB-идентификаторы или позволяет выйти за границы выбранного источника, используйте приватное сообщение об уязвимости через вкладку Security репозитория, если оно доступно. Не прикладывайте реальные фотографии, журналы с личными путями или данные авторизации к публичному issue.

Для обычной ошибки достаточно версии приложения, версии Windows и обезличенного описания воспроизведения. Поддерживается текущая preview-версия.
