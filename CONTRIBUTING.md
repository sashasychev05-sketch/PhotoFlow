# Внести вклад

Сначала откройте issue с конкретным сценарием и ожидаемым результатом. Личные фото, пути и идентификаторы устройств заменяйте обезличенными примерами.

Для разработки нужны Windows, .NET SDK 10 и Windows SDK. Выполните `scripts/photoflow.ps1 restore`, затем `build` и `test`. Тесты используют искусственные источники и рабочие GUID-каталоги; реальные телефоны не нужны.

Изменения WPD дополнительно проверяйте на устройстве. Не выдавайте распознавание расширения за декодирование и не добавляйте скрытую загрузку оригинала в строгом режиме. Учитывайте весь каталог при массовом отборе. Сохраняйте лицензии и обновляйте THIRD_PARTY_NOTICES при новых заимствованиях.

Скриншоты для PR делайте на кнопке «Демо». Подробности приёмки — в docs/DEVICE-VALIDATION.md.
